# stock_dashboard

계좌 자산을 가져와 포트폴리오를 분석하는 대시보드입니다. **내 엑셀(주식.xlsx)을 브라우저에서 불러오거나**, 가상 데이터로 둘러볼 수 있습니다. 이후 마이데이터 API를 연결할 수 있도록 데이터 계층을 분리해 두었습니다.

## 엑셀 가져오기 (개인 데이터 보호)

- 오른쪽 위 **엑셀 가져오기**로 `.xlsx` 를 고르면 파일을 **브라우저 안에서만** 읽습니다. 서버로 보내지 않습니다.
- 읽은 결과와 그룹 설정은 그 브라우저의 localStorage 에만 저장됩니다. 다른 기기 · 다른 브라우저에서는 다시 가져와야 합니다.
- 저장소에는 개인 데이터를 넣지 않습니다 (`*.xlsx` 는 `.gitignore` 에 등록).

| 시트 | 읽는 내용 |
| --- | --- |
| Summary | 계좌별 원금 · 목표 · 단위(만원), 년도 표(연초 총자산 · 연중 변경), 월별 표(계좌별 입금 · 기말자산) |
| 투자내역 | 매수 · 매도 기록. 판매가격 · 판매날짜가 없으면 보유 중으로 보고 종목별로 합산, 매도 건은 실현손익 · 메모로 표시 |
| 해외주식리스트 | 달러 종목 이름, 환율 |

표는 셀 위치가 아니라 머리글('년도', '날짜', '기말자산', '종목' …)로 찾으므로 행이 늘어나도 그대로 동작합니다.
엑셀에 현재가가 없어서 보유 종목은 매입가로 계산하며, 종목의 ✎ 버튼으로 현재가를 입력하면 비중 · 손익에 반영됩니다.

배포 주소: https://jungboungho.github.io/stock_dashboard/

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 계좌 필터 | 전체 / 계좌별 전환 (모든 지표가 함께 바뀜) |
| 요약 | 총 평가금, 투자 원금, 수익금(단순 수익률), 시간가중수익률(TWR, 연환산), 최근 12개월 배당 |
| 자산 추이 | 위: 원금(회색 계단) + 평가금(선), 둘 사이 = 수익금(빨강 수익 / 파랑 손실). 아래: 수익률(단순 / TWR 전환). x축 공유, 마우스 위치 동기화 |
| 기간 설정 | 1개월 · 3개월 · 6개월 · 올해 · 1년 · 전체, 또는 날짜 직접 입력 |
| 기간 비교 | 비교 기간(직전 기간 / 전년 동기 / 직접 입력)과 수익금 · TWR · 순입금 · 배당 비교표, 시작일 = 0% 로 맞춘 누적 수익률 겹쳐 보기 |
| 연도별 수익률 | 연초 자산 · 연중 순입금 · 연말 자산 · 손익 · 연초대비 수익률 · 목표 달성 여부 표, 연도별 연초대비 수익률 곡선(1~12월, 목표선) |
| 그룹별 비중 | **내 그룹**(직접 만든 그룹) · 자산유형 · 지역 · 섹터 · 계좌 · 통화 기준 도넛 + 평가손익 · 수익률 표 |
| 그룹 관리 | 그룹 만들기 · 이름 변경 · 순서 변경 · 삭제(종목은 미분류로), 그룹 줄을 누르면 소속 종목과 그룹 내 비중 표시 |
| 그룹 안 종목 | 보유 종목을 그룹에 추가 · 다른 그룹으로 이동 · 빼기, 데이터에 없는 종목 직접 추가 · 수정 · 삭제, 현재가 직접 입력 |
| 배당 | 연도별 합계, 월별 막대(선택 기간 강조), 종목별 누적 상위 |
| 보유 종목 | 수량, 평균단가(이동평균), 현재가, 평가금, 평가손익, 비중 |

## 계산 규칙

- 원금 = 누적 입금 − 누적 출금
- 평가금 = 현금 + Σ(수량 × 종가 × 환율)
- 수익금 = 평가금 − 원금 (매매차익 · 배당 · 환차익 포함)
- 단순 수익률 = 수익금 / 원금
- TWR = Π(1 + rₜ) − 1, rₜ = Vₜ / (Vₜ₋₁ + 입출금ₜ) − 1 → 입출금 시점 · 규모와 무관한 운용 성과
- 기간 수익금 = 종료 평가금 − 시작 직전 평가금 − 기간 순입금
- 그룹 · 종목 표의 평가손익 = 현재 보유분의 평가금 − 매입원가 (이미 실현한 손익과 배당은 빠지므로 요약의 수익금과 다름)
- 연초대비 수익률 = (연말 자산 − 연초 자산 − 연중 순입금) / (연초 자산 + 연중 순입금) — 엑셀 Summary 의 '이익' · '연초대비' 와 같은 식
  - 월별: 그달 말 자산 / (연초 자산 + 1월~그달 순입금) − 1
  - 연초 자산 = 전년 마지막 평가금. 엑셀 년도 표에 값이 있으면 그 값을 그대로 사용

## 마이데이터 연결 계획

1. 마이데이터 접근토큰은 브라우저에 둘 수 없으므로 토큰을 보관하고 API를 대신 호출하는 **중계 서버**를 둔다.
2. 중계 서버가 계좌 목록 · 보유 상품 · 거래내역 응답을 `types.ts` 형태로 변환해 돌려준다.
3. 마이데이터는 과거 일별 시세를 주지 않으므로, 자산추이용 가격은 시세 API를 쓰거나 매일 평가 스냅샷을 저장해 채운다.
4. `main.ts`에서 `new DummyProvider()`를 `new MyDataProvider('<중계 서버 주소>')`로 바꾼다.

## 개발

```powershell
npm install
npm run dev      # http://localhost:5173/stock_dashboard/
npm test
npm run build
```

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → Pages 배포를 진행합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔야 합니다.

> 더미 데이터의 종목 이름만 실제이고 가격 · 거래 · 배당은 모두 임의 값입니다.
