# stock_dashboard

계좌 자산을 가져와 포트폴리오를 분석하는 대시보드입니다. 오른쪽 위 **마이데이터 동기화** 메뉴로 내 데이터를 불러오며, 불러오기 전에는 샘플 데이터(보유 종목 · 관심 종목 · 지수 · 환율 포함)를 보여줍니다.

배포 주소: https://jungboungho.github.io/stock_dashboard/

## 내 계좌로 쓰기 (처음 한 번)

각자 **자기 GitHub · 자기 Cloudflare · 자기 NH 앱키**로 따로 운영합니다. 앱키 · 시크릿은 자기 Cloudflare 비밀값에만 들어가고, 이 저장소 · 사이트 · 엑셀에는 들어가지 않습니다 (앱키가 있으면 주문까지 가능하므로 엑셀 · 브라우저에 두지 않음).

1. **저장소 Fork** — GitHub 에서 Fork → 내 저장소 Settings → Pages → Source 를 **GitHub Actions** 로. Actions 탭에서 워크플로 실행을 허용하면 `https://<내 아이디>.github.io/<저장소 이름>/` 에 대시보드가 올라갑니다.
2. **NH 앱키 발급** — [NH PLUG 포털](https://www.nhplug.com) (N2 고객은 n2plug.com) 에서 Open API 를 신청해 앱키 · 앱시크릿을 받습니다.
3. **내 PC 준비** — Node.js 22 를 설치하고, Fork 한 저장소를 받아 `npm install`.
4. **중계 서버 배포** — Cloudflare 에 무료 가입한 뒤:

   ```powershell
   npm run worker:setup
   ```

   - 브라우저로 Cloudflare 로그인 → 대시보드 주소(내 GitHub Pages) 확인 → 저장소(KV) 생성 → 배포 → NH 앱키 · 시크릿 입력(화면에 안 보임) → 접속 토큰 자동 생성 순서로 진행합니다.
   - 처음이면 workers.dev 하위 도메인을 정하라는 안내가 나옵니다. 등록하고 다시 실행하면 이어서 진행합니다.
   - 끝나면 엑셀 `설정` 시트에 넣을 **중계 서버 주소 · 접속 토큰**을 보여줍니다 (토큰은 `local-data/worker-token.txt`, git 제외).
   - 바꾸지 않고 확인만: `npm run worker:setup -- --dry-run` · 토큰 새로 만들기: `npm run worker:setup -- --new-token`
5. **엑셀 준비** — 대시보드 샘플 화면의 **엑셀 양식 내려받기**(`public/template.xlsx`, 숫자는 예시)를 받아 Summary · 입금내역을 내 값으로 채우고, `설정` 시트에 주소 · 토큰을 넣어 구글 드라이브 등에 둡니다. **이 엑셀은 다른 사람과 공유하지 마세요** (토큰으로 내 잔고를 조회할 수 있음).
6. **사용** — 대시보드에서 ① 엑셀 불러오기 → ② 최신 정보 가져오기 → ③ 엑셀 업데이트. 첫 ③ 때 `설정` 시트에 `NH 계좌 ####` 줄이 생기면 B열에 대시보드 계좌 이름(입금내역 머리글과 같게, 예: `종합`)을 적고 다시 불러오면 그 계좌가 동기화됩니다.

코드를 고친 뒤 중계 서버만 다시 올릴 때: `npm run worker:deploy`

| 순서 | 메뉴 | 동작 |
| --- | --- | --- |
| ① | 엑셀 불러오기 | `주식.xlsx` 를 **브라우저 안에서만** 읽음 (Summary · 입금내역 · 보유종목 · 그룹 · 관심종목 · 배당 · 일별 / 월별 자산추이 · 설정) |
| ② | 최신 정보 가져오기 | 중계 서버 → NH 투자증권 Open API: 이름이 정해진 NH 계좌의 잔고 · 배당을 통째로 받고, 나머지 계좌(ISA · 연금 · IRP) 종목과 **관심 종목 · 지수 · 환율 · 금**은 현재가 · 등락률 · 종가 · 종가 등락률을 갱신. 왼쪽 메뉴의 **최신 정보 가져오기** 버튼도 같음 |
| - | (편집) | 보유 종목 표에서 계좌별로 종목 · 수량 · 매입금액 · 현금 수정, 그룹별 비중에서 그룹 만들기 · 종목 배정, 관심 종목 그룹 · 종목 추가 / 이동 / 삭제 |
| ③ | 엑셀 업데이트 | 원본 엑셀의 다른 시트는 그대로 두고 `보유종목` · `그룹` · `관심종목` · `배당` · `일별 자산추이` · `월별 자산추이` 시트를 새로 쓰고, `설정` 시트에는 처음 본 NH 계좌 줄을 덧붙이고 `보유종목 컬럼` 줄(화면의 컬럼 설정)을 저장. Summary 기말자산은 일별 기록이 시작된 달부터 `월별 자산추이`를 참조하는 수식으로 연결 (그 전 달은 직접 입력한 값 그대로). PC 크롬 · 엣지는 고른 파일에 바로 저장, 그 외(휴대폰 등)는 파일을 내려받음 |
| - | 사진으로 계좌 업데이트 | 증권사 앱 계좌 화면 캡처(여러 장 가능)를 **브라우저 안에서** 글자 인식 → 계좌 · 종목 · 수량 · 평가금 · 손익 · 현금을 읽고, 지금 보유 종목과 이름 / 수량 / 금액으로 맞추고, 보유하지 않은 종목은 종목 목록에서 이름 앞부분으로 찾아 채운 뒤(여러 개면 고르는 목록) 확인 화면에서 고쳐서 적용. 화면 총액과 읽은 합계가 맞는지 표시 (보유 종목 표의 "사진으로 업데이트" 버튼도 같음) |
| - | 종목 목록 업데이트 *(동기화 버튼 왼쪽)* | 중계 서버를 거쳐 NH 국내 · 해외 종목 마스터를 받아 국내 전체 + 미국 종목 목록을 만들고, **지수 · 환율 · 금 목록과 함께 중계 서버에 공유 목록으로 저장** → 어느 기기에서든 한 번 누르면 모든 기기가 같은 최신 목록을 씀 (관심 종목 추가 · 사진 업데이트의 종목 찾기). 읽는 순서: 공유 목록 → 이 브라우저 저장본 → `public/instruments.json`(국내, 기본). 어느 쪽이든 지수 · 환율 · 금은 항상 최신 목록을 붙임 |
| - | 불러온 데이터 지우기 | 이 브라우저에 저장된 내 데이터 · 그룹 설정 삭제 |

- 내 데이터의 그룹은 엑셀 `그룹` 시트에서 시작하고, 샘플 데이터의 그룹과 따로 저장됩니다.
- 앞으로 엑셀에는 `입금내역` 만 채우면 되고, 보유 종목 · 그룹 · 관심 종목 목록은 ③ 엑셀 업데이트가 채웁니다.
- 저장소에는 개인 데이터를 넣지 않습니다 (`*.xlsx`, `credential*.txt`, `proxy/.dev.vars`, `local-data/` 는 `.gitignore`).

### 엑셀 시트

| 시트 | 내용 |
| --- | --- |
| Summary | 계좌별 원금 · 목표 · 단위(만원), 년도 표(연초 총자산 · 연중 변경), 월별 표(계좌별 입금 · 기말자산) |
| 입금내역 | 날짜별 · 계좌별 입금 (음수 = 출금 · 계좌 간 이체) → 계좌별 입금 화면 |
| 해외주식리스트 | 환율 (보유종목에 환율이 없을 때) |
| 보유종목 *(대시보드가 씀)* | 기준일 · 계좌 · 종목코드 · 종목명 · 통화 · 수량 · 평균단가 · 현재가 · 등락률 · 종가 · 종가등락률 · 환율 · 매입금액 · 평가금액 · 평가손익 · 그룹. 종목코드 `현금` 줄은 계좌 현금 |
| 그룹 *(대시보드가 씀)* | 그룹 · 종목코드 · 종목명 (그룹마다 여러 줄) |
| 관심종목 *(대시보드가 씀)* | 그룹 · 종목코드 · 종목명 · 통화 · 현재가 · 등락률 · 종가 · 종가등락률. 그룹 순서대로, 종목이 없는 그룹은 종목코드가 빈 줄 하나. 지수 · 환율 · 금은 `IDX:` · `FX:` · `GOLD:` 코드 (예: `IDX:N225`, `FX:EURKRW`, `GOLD:KRX`). **시트가 없는 엑셀은 '발견' 그룹(코스피 · 나스닥 · S&P500 · 다우존스 · 필라델피아 반도체 · 원/달러 · 원/엔 · 금)으로 시작** |
| 일별 자산추이 *(대시보드가 씀)* | 날짜 · 총자산 · 투자원금 · 수익금 · 수익률 · 계좌별 평가금 — 동기화 · 편집한 날마다 한 줄 (예전 `자산스냅샷` 시트는 이 이름으로 바뀜) |
| 월별 자산추이 *(대시보드가 씀)* | 월 · 기말자산 · 순입금 · 투자원금 · 수익금 · 수익률 · 월 수익률 · 연초대비 · 기준(Summary / 일별) |
| 배당 *(동기화 + 직접 작성)* | 날짜 · 계좌 · 종목코드 · 종목명 · 통화 · 금액 · 환율 · 원화금액 · 출처. 출처 `API` = 중계 서버 배당 장부(NH 종합거래내역)에서 온 것: 동기화 때 서버가 장부 최신일 − 14일부터 다시 받고, 달러 배당은 **그날 USD/KRW(NH 환율 일별 시세)** 로 원화금액을 정해 고정. 출처를 비우거나 `직접` = 직접 적은 배당(ISA · 연금 · IRP 등, 동기화가 건드리지 않음, 환율 칸에 적은 값으로 환산) |
| 설정 *(직접 작성 + 계좌 줄 · 컬럼 설정)* | `중계 서버 주소` · `접속 토큰` 오른쪽 칸 값 → 엑셀을 불러오면 그 브라우저의 동기화 설정으로 저장. `NH 계좌 1234` 오른쪽 칸 = 끝자리 1234 NH 계좌를 부를 대시보드 계좌 이름(예: ISA) — 동기화 때 중계 서버에 함께 보냄. ③ 엑셀 업데이트는 NH 가 새로 응답한 계좌의 `NH 계좌 ####` 줄을 B열을 비워 덧붙임. `보유종목 컬럼` 오른쪽 칸 = 보유 종목 표 컬럼 순서(쉼표로 구분, 앞에 `-` 를 붙이면 숨김, 예: `계좌, 그룹, 수량, -평균단가, 현재가, …`) — ③ 엑셀 업데이트가 화면 설정을 저장하고 ① 엑셀 불러오기 때 그 기기에 적용 (엑셀에서 직접 고쳐도 됨) |

투자내역 시트는 최신이 아니어서 읽지 않습니다. 일별 기록이 있는 달은 그 날짜들로 자산 추이를 그리고 (원금은 그달 입금내역을 날짜까지 더함), 없는 달은 Summary 기말자산(비면 월별 자산추이)을 씁니다.
표는 셀 위치가 아니라 머리글로 찾으므로 행이 늘어나도 그대로 동작합니다.

## 계산 규칙

- 원금 = 누적 입금 − 누적 출금
- 평가금 = 현금 + Σ(수량 × 현재가 × 환율)
- 수익금 = 평가금 − 원금 (매매차익 · 배당 · 환차익 포함)
- 단순 수익률 = 수익금 / 원금
- TWR = Π(1 + rₜ) − 1, rₜ = Vₜ / (Vₜ₋₁ + 입출금ₜ) − 1 → 입출금 시점 · 규모와 무관한 운용 성과
- 기간 수익금 = 종료 평가금 − 시작 직전 평가금 − 기간 순입금
- 그룹 · 종목 표의 평가손익 = 현재 보유분의 평가금 − 매입원가 (이미 실현한 손익과 배당은 빠지므로 요약의 수익금과 다름)
- 연초대비 수익률 = (연말 자산 − 연초 자산 − 연중 순입금) / (연초 자산 + 연중 순입금) — 엑셀 Summary 의 '이익' · '연초대비' 와 같은 식
  - 월별: 그달 말 자산 / (연초 자산 + 1월~그달 순입금) − 1
  - 연초 자산 = 전년 마지막 평가금. 엑셀 년도 표에 값이 있으면 그 값을 그대로 사용
- 현재가 · 등락률 vs 종가 · 종가 등락률 (한국 시간에는 미국 종목의 네 값이 모두 다를 수 있음)
  - 현재가 · 등락률 = 지금 시세의 전일 대비. 미국 종목은 주간 · 장전 · 장후 거래 포함, 국내 종목은 일자별 시세 두 줄로 계산 (NH 현재가 등락률은 부호가 없어서)
  - 종가 · 종가 등락률 = **마지막으로 끝난 정규장** 종가와 그 전일 대비. 그 시장 현지 시각으로 장중이면 오늘 줄은 건너뜀 (국내 09:00–15:30 서울, 미국 09:30–16:00 뉴욕, 니케이 09:00–15:30 도쿄 등)
  - 환율은 24시간 움직여 종가 = 어제 마지막 값. 원화 환율은 원/달러 × (그 통화 1단위의 달러 값) × 단위(100엔 · 100루피아)로 환산하고 등락률도 두 값의 변화를 곱해 계산
  - 금(KRX 금현물)은 원/g, 등락률은 NH 등락 부호로 바로잡음

## 중계 서버 (NH 투자증권 Open API)

앱키 · 시크릿은 브라우저나 공개 저장소에 둘 수 없어서 중계 서버에만 둡니다. 브라우저는 서버 주소와 접속 토큰만 압니다.

**내 PC에서 (개발 · 확인)**

```powershell
copy proxy\.dev.vars.example proxy\.dev.vars   # CRED_FILE · NH_ACCOUNTS · PROXY_TOKEN 입력
npm run proxy                                    # http://localhost:8787
```

**Cloudflare Worker (휴대폰에서도 사용)** — `npm run worker:setup` (위 "내 계좌로 쓰기" 4번). `proxy/wrangler.toml` 은 각자 만드는 파일이라 git 에서 제외되고, 양식은 `proxy/wrangler.example.toml` 입니다. 비밀값: `NH_APP_KEY` · `NH_APP_SECRET` · `PROXY_TOKEN` (선택: `NH_ACCOUNTS` = `1234:종합,5678:금계좌` — 엑셀 `설정` 시트로 대신할 수 있음). KV(`TOKENS`)에는 NH 토큰 · 공유 종목 목록 · 배당 장부를 둡니다.

배포 후 엑셀 `설정` 시트에 Worker 주소와 `PROXY_TOKEN` 을 적어 두면, 어느 기기든 엑셀을 불러올 때 동기화 설정이 채워집니다 (설정이 없을 때 ②를 누르면 입력 창이 뜹니다).
② 최신 정보 가져오기는 NH 가 응답하는 **모든 실계좌**를 확인합니다. 이름이 정해진 계좌(서버 `NH_ACCOUNTS` 또는 엑셀 `설정` 시트의 `NH 계좌 1234` 줄)는 잔고 · 배당을 최신으로 바꾸고, 이름이 없는 계좌는 반영하지 않고(엑셀 값 유지) 끝자리와 종목 수만 알려 줍니다. 지금 NH Open API 는 위탁 · 금현물 계좌만 응답해서 연금저축 · IRP · ISA 는 보유 종목 표나 사진으로 수정하고, 시세만 자동으로 갱신됩니다. 한 번에 보유 + 관심 종목 120개까지 시세를 받습니다.

**지수 · 환율 · 금** (`proxy/src/markets.ts`) — NH 해외 지수/환율 기간별 시세 API(`symbolIndexFxPeriod`)와 KRX 금현물 시세로 받습니다. NH 가 코드표를 공개하지 않아 실제 응답으로 확인한 코드만 넣었습니다.

| 지역 | 지수 | 환율 |
| --- | --- | --- |
| 한국 | 코스피 · 금(KRX 금현물, 원/g) | 원/달러 |
| 미국 | S&P500 · 나스닥 · 나스닥100 · 다우존스 · 다우존스 운송 · NYSE 종합 · 필라델피아 반도체 · 필라델피아 금/은 | |
| 일본 | 니케이225 | 원/엔(100엔) · 엔/달러 |
| 중국 · 홍콩 | 상해종합 · 항셍 · 홍콩 H지수 | 원/위안 · 위안/달러 · 원/홍콩달러 |
| 인도 | SENSEX | |
| 유럽 | 독일 DAX · 유로STOXX50 | 원/유로 · 달러/유로 · 원/스위스프랑 |
| 기타 | 대만 가권 · 베트남 VN · 태국 SET · 캐나다 S&P/TSX | 원/대만달러 · 원/호주달러 · 원/캐나다달러 · 원/싱가포르달러 · 원/태국바트 · 원/인도네시아루피아(100) |

NH 에서 조회되지 않는 것: 코스닥, TOPIX, 심천 · CSI300, NIFTY, FTSE100, CAC40, 영국 파운드, 인도 루피 (NH `INR` 코드는 인도네시아 루피아를 돌려줌). 새 코드를 찾으면 `markets.ts` 에 한 줄 추가하고 `npm run worker:deploy`(시세) + `main` 에 push(사이트 검색 목록) 하면 됩니다.

## 개발

```powershell
npm install
npm run dev             # http://localhost:5173/
npm test
npm run build
```

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → Pages 배포를 진행합니다 (저장소 Settings → Pages → Source = GitHub Actions).
공개 저장소이지만 코드와 샘플 데이터만 올라갑니다. 실제 값은 `*.xlsx` 를 git에서 제외하고, 엑셀은 각 브라우저 안에서만 읽어 그 브라우저에 저장합니다.

### 여러 기기에서 보기
`주식.xlsx` 를 구글 드라이브에 두고, 각 기기(PC · 휴대폰)에서 **① 엑셀 불러오기** 로 드라이브의 파일을 고르면 됩니다.
③ 엑셀 업데이트로 보유종목 · 그룹 · 관심종목을 엑셀에 저장해 두면 다른 기기에서도 같은 구성으로 불러옵니다.

> 더미 데이터의 종목 · 지수 이름만 실제이고 가격 · 거래 · 배당 · 지수 · 환율 값은 모두 임의 값입니다.
